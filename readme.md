## 🎯 Sobre a tradução

Este projeto disponibiliza a tradução de **Agent 64: Spies Never Die para Português Brasileiro**, buscando preservar o estilo de espionagem, o humor, a personalidade dos personagens e a atmosfera retrô do jogo.

Agent 64 mistura espionagem, conspirações, infiltração, gadgets, instalações secretas e tiroteios em uma aventura inspirada nos shooters de console dos anos 90.

Entre os conteúdos traduzidos estão:

* 🎬 Diálogos e legendas
* 📋 Briefings de missão
* 🎯 Objetivos
* 🖥️ Interface e menus
* 🎮 Tutoriais e mensagens de gameplay
* 🔫 Armas e equipamentos
* 🤖 Configurações e opções de bots
* 🏆 Modos Arena
* 📁 Contracts
* 🌀 Paradox Modes
* ⚙️ Configurações
* 📢 Mensagens e notificações
* 🕵️ Textos relacionados à história e à investigação

A localização foi preparada pensando em um **Português Brasileiro natural**, mantendo os textos de interface claros e objetivos e adaptando os diálogos para soarem naturais em português.

## 📥 Download

Baixe o arquivo:

```text
PTBR.zip
```

Dentro dele você encontrará:

```text
TranslationFile.tsv
```

Esse é o arquivo responsável pelos textos utilizados pelo jogo.

---

## 🔧 Instalação

### 1. Abra a pasta do jogo

Na Steam:

1. Abra sua **Biblioteca**.
2. Clique com o botão direito em **Agent 64: Spies Never Die**.
3. Vá em **Propriedades**.
4. Abra **Arquivos instalados**.
5. Clique em **Explorar**.

Isso abrirá a pasta de instalação do jogo.

---

### 2. Localize o arquivo original

Dentro da pasta do jogo, localize:

```text
TranslationFile.tsv
```

Caso necessário, utilize a pesquisa do Explorador de Arquivos do Windows.

> 💡 **Recomendado:** faça uma cópia do `TranslationFile.tsv` original antes de substituí-lo.

---

### 3. Instale a tradução

Extraia o arquivo:

```text
PTBR.zip
```

e copie o nosso:

```text
TranslationFile.tsv
```

para o mesmo local onde está o arquivo original do jogo.

Quando o Windows perguntar se deseja substituir o arquivo existente, confirme.

---

## 🇧🇷 Ativando o Português Brasileiro

Atualmente, a tradução utiliza o **slot de idioma Francês** do próprio jogo para carregar o PT-BR.

Depois de instalar:

1. Abra **Agent 64: Spies Never Die**.
2. Entre nas opções de idioma.
3. Selecione:

```text
Français / French
```

Apesar de aparecer como **Francês** no menu, os textos serão exibidos em **Português Brasileiro**.

> ⚠️ Não altere o arquivo nem renomeie a coluna `Français`. Ela é utilizada pelo jogo para reconhecer corretamente a localização.

---

## 🗑️ Desinstalação

Para remover a tradução, basta restaurar o `TranslationFile.tsv` original.

Caso não tenha feito um backup:

1. Abra a Steam.
2. Clique com o botão direito em **Agent 64: Spies Never Die**.
3. Vá em **Propriedades → Arquivos instalados**.
4. Clique em **Verificar integridade dos arquivos**.

A Steam restaurará o arquivo original.
